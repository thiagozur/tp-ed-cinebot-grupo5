# Kino

Kino es un sistema interactivo con una interfaz en consola que permite buscar, listar y filtrar un catálogo de películas según títulos, géneros o directores, además de obtener recomendaciones de películas relacionadas y rankings de las mejor calificadas. La aplicación carga sus datos de forma dinámica desde un archivo JSON y estructura su arquitectura desacoplando la interfaz de usuario de la lógica del catálogo.
